# Changelog

## 1.2.8 - 2026-06-20

Applies to:

- `firstaid-1.2.7+fabric1.21.1`
- `firstaid-1.2.7+fabric26.1`
- `firstaid-1.2.7+fabric26.2`
- `firstaid-1.2.7+neoforge1.21.1`
- `firstaid-1.2.7+neoforge26.1`
- `firstaid-1.2.7+neoforge26.2`
- `firstaid-1.2.7+forge1.20.1`

### Added

- Added `/firstaid suppression off` to disable projectile near-miss suppression triggers.
- Added persistent `projectileSuppressionEnabled` server config support.

### Changed

- `/firstaid suppression dynamic` and `/firstaid suppression mild` now re-enable projectile near-miss suppression while selecting the intensity mode.
- Updated operator command tips and README command documentation for `dynamic|mild|off`.

### Fixed

- Synced the projectile suppression enabled state to Forge and NeoForge clients when command settings change.
