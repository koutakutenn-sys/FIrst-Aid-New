# Changelog

## 1.2.7 - 2026-06-20

Applies to:

- `firstaid-1.2.7+fabric1.21.1`
- `firstaid-1.2.7+fabric26.1`
- `firstaid-1.2.7+fabric26.2`
- `firstaid-1.2.7+neoforge1.21.1`
- `firstaid-1.2.7+neoforge26.1`
- `firstaid-1.2.7+neoforge26.2`
- `firstaid-1.2.7+forge1.20.1`

### Added

- Added Fabric 26.2 and NeoForge 26.2 loader/version modules.

### Changed

- Ported the Fabric 26.2 module to Minecraft 26.2, Fabric Loader 0.19.3, Fabric Loom 1.17.11, Fabric API 0.152.2+26.2, and Gradle 9.5.1.
- Updated Fabric 26.2 client GUI integration for the Minecraft 26.2 GUI/HUD API changes.
- Updated Fabric 26.2 resource metadata for Minecraft 26.2 pack format requirements.
- Bumped all maintained loader/version modules to loader-specific `1.2.7` release strings.

### Fixed

- Fixed Fabric 26.2 client startup crashes caused by renamed or retargeted Minecraft 26.2 camera and HUD mixin targets.
- Fixed Fabric 26.2 runClient startup by updating the Camera mixin vector shadows and retargeting the vanilla heart HUD injection.
- Synced the latest damage model and health distribution handling across the maintained Fabric, Forge, and NeoForge modules.
- Fixed copied 26.1-era status summary behavior in the 26.x modules so downed/critical status text stays owned by the centered status overlay.
