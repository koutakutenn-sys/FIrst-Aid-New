# First Aid New 1.3.2

*Fixes sticky nerves, and lets you shock yourself back on your feet.*

Applies to:

- `firstaid-1.3.2+fabric1.21.1`
- `firstaid-1.3.2+fabric26.2`
- `firstaid-1.3.2+neoforge1.21.1`
- `firstaid-1.3.2+neoforge26.2`
- `firstaid-1.3.2+forge1.20.1`

Closes GitHub issue [#7](https://github.com/maoruiQa/FIrst-Aid-New/issues/7).

## Feedback audio (issue #7)

### No more stuck ringing / heartbeat after revival

- Hard-stops tinnitus and heartbeat on death, respawn, login/disconnect, and successful rescue.
- Rescue clears residual suppression and starts a short audio mute window so revival does not re-arm ringing immediately.
- Heartbeat no longer sustains from tiny leftover suppression intensity.

### Ear ringing is rarer and more intentional

Tinnitus now comes from:

1. **Explosion** damage  
2. **Head trauma** (meaningful HP lost on the head this hit)  
3. **Sudden strong full-body shock** (~3+ hearts in one hit)  
4. **Overpowering suppression only** (intensity ≥ ~0.85), short and quiet — not mild near-miss pressure  

Near-miss still drives camera/desaturation suppression, but no longer always rings the ears.

## Self-defibrillator

While critical-downed, hold a defibrillator and hold **Use** for 3 seconds to revive yourself (1 durability). Bandage/plaster remain other-player rescue items only.

## Technical notes

- Damage model fields: `tinnitusCueId`, `tinnitusCueSeverity`, `audioMuteTicks` (synced via existing damage-model NBT).
- Network: `MessageClientRequest.RequestType.ATTEMPT_SELF_DEFIB` (appended; no ordinal break for older clients that only send previous types).
- Client: tracked tinnitus instances so death/rescue can stop them mid-play.
